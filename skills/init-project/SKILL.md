---
name: init-project
description: "Prepare the current project for the mr plugin: create docs/plans/README.md and docs/model-routing-log.md from the plugin templates and add the policy pointer to CLAUDE.md. Use before the first delegation in a project."
---

Run `mr-init --claude-md` from the project root.

If the project's CLAUDE.md is generated by a script, run `mr-init` without `--claude-md` instead and add the printed pointer line through that generator.

Report every line the command printed.

Add docs/handoffs/ to the project's .gitignore if it is not listed; tier agents write their handoff files there.
