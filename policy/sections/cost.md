## Cost reference
Prices as of 2026-11-12; check current pricing. Per 1M tokens, input / output / cache read: Haiku 5.5 0.10 / 0.50 / 0.01 with prompts up to 100K tokens (0.50 / 2.50 / 0.05 above); Sonnet 5.5 2 / 10 / 0.10; Opus 5.5 4 / 20 / 0.20. Executors produce the most tokens, so they run on the cheapest tier that passes verification. Planners produce few tokens, so a stronger model there is cheap insurance. A verifier costs about as much as the work it checks, and for Haiku tasks often more, so it runs only where risk, a task run below its planned tier, or a failed check justifies it. Risk tasks get their own verifier; other triggered tasks share one batch verifier per group at the end of the plan. `{{plugin_name}}-cost` prices a session's subagent tokens at these rates.
